Spec

Transport: stdio / sse / streamable-http
Deps: mcp + pydantic
No external AI API key
Local audit: read-only

Style profile

Paper & Inkは選択可能な美的方向。ルールは用途とブランドに合わせる。

「提案で終わらず、
根拠と差分へ。」

Paper & Inkはopenmcpartの出発点であり、すべてのブランドに強制するルールではない。18のMCPツールによる提案に加え、ローカルHTML/CSSの静的監査では問題候補とソース位置を示す。ファイルは読み取り専用で、結果はブラウザや支援技術でも確認する。

Principles

  • ユーザーが選んだブランド方向を尊重
  • 監査結果に根拠とソース位置を付ける
  • 自動チェックと手動確認を分ける
  • ローカル監査は読み取り専用
  • スタイルの好みを普遍的な不具合と呼ばない
  • 提案を実装・検証につなげる

18 MCP Tools — Highlights

道具は
少なく、
切れ味を。

18のMCPツール、4つのリソース、3つのプロンプト。ローカルHTML/CSS監査とトークン抽出を追加。コードは実行せず、結果は候補として確認できます。

01 / Color

generate_color_palette

ベースカラーまたはムードから調和の取れたパレット。complementary, analogous, triadic。CSS変数で出力。

Paper #fdfcfa / Ink #121212 / Terracotta #c45a3c — No purple

02 / Color

check_color_contrast

WCAG AA/AAA判定 + 色覚多様性シミュレーション。アクセシビリティは洗練の条件。

#ffffff on #121212 → 19.2:1 AAA Pass
#fdfcfa on #c45a3c → 4.8:1 AA Pass
Deutera / Protano / Tritano simulation included

03 / Typography

suggest_typography_pairing

日本語対応。Instrument Serif + Inter Tight。セリフで脱AI。Google Fonts URL付き。

Instrument Serif

Inter Tight — 見出しはセリフ、本文はサンセリフ。ウェイトは400と500だけ。

04 / Layout

suggest_layout

SaaS, Dashboard, Blog等。12colだが非対称に。セクション間160px。8pt grid。

Left 5col content / Right 7col whitespace — Asymmetrical

05 / Tokens

generate_design_tokens

色・タイポグラフィ・余白・角丸などの基本トークンを生成。CSS変数、Tailwind config、JSON、DTCG-style JSONを出力。Figmaプラグインとの互換性は利用先で確認してください。

:root { --paper: #fdfcfa; --ink: #121212; --hairline: 0.5px solid #e8e3dc; --radius: 0px; }

06 / Sophisticated

generate_sophisticated_ui

NEW AIっぽくないUI仕様生成。紫グラデ、24px角丸、影を避ける具体的なCSSを出力。

Avoid: purple gradient, 24px radius, shadow-lg, ✨
Instead: paper #fdfcfa, 0px radius, hairline, serif, 160px whitespace

07 / Style profile

critique_ai_look

説明文に書かれたパターンだけをヒューリスティックに検出。美的好みは不具合と決めつけない。

指摘なしは「問題なし」の証明ではありません。ブランドに合うなら、そのまま選べます。

08 / Project audit

audit_project

指定したローカルHTML/CSSを読み取り専用で確認。alt、フォームラベル、見出し、静的コントラストなどの候補をソース位置付きで返す。

openmcpart audit ./my-app --fail-on high

No code execution / No network / No writes

09 / Design tokens

extract_project_tokens

CSS変数、色、フォント、余白、角丸、影の候補を読み取り専用で抽出。JSONまたはMarkdownで利用。

openmcpart tokens ./my-app --format json

Code Example — Non-AI Button

影も、
丸みも、
いらない。

AIは「目立たせる = 影 + グラデ + 丸み」と学習した。洗練は逆。紙とインク、0.5pxの線、0pxの角。hoverはopacity 0.85だけ。scaleはしない。

/* AIっぽいボタン - 避ける */ .button-ai { background: linear-gradient(135deg, #8b5cf6, #3b82f6); border-radius: 24px; box-shadow: 0 8px 32px rgba(139, 92, 246, 0.3); transform: scale(1); transition: all 0.3s bounce; } .button-ai:hover { transform: scale(1.05); } /* 洗練されたボタン - こちら */ .button-refined { background: #121212; color: #fdfcfa; border: 0.5px solid #121212; border-radius: 0px; height: 44px; padding: 0 24px; font-size: 13px; letter-spacing: 0.04em; text-transform: uppercase; transition: opacity 150ms ease-out; } .button-refined:hover { opacity: 0.85; }

Height 44px / Radius 0 / Border 0.5px / Transition 150ms / No scale
